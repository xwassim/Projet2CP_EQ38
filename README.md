# Projet2CP_EQ38 — La Crèche d'à Côté

## Français

Projet académique réalisé en équipe à l'École Nationale Supérieure d'Informatique (ESI Alger) durant l'année 2022/2023.

### Description

**La Crèche d'à Côté** est une application web permettant de rechercher et consulter des crèches en Algérie selon différents critères.

La plateforme permet notamment aux parents de rechercher des crèches, consulter leurs informations, réserver une place, prendre rendez-vous et laisser des avis. Elle propose également des fonctionnalités destinées aux responsables de crèches et aux administrateurs. :chatgpt-content-reference{index="0"}

### Technologies

- React.js
- Node.js
- Express.js
- MongoDB / Mongoose
- Tailwind CSS

La solution a été développée avec la stack MERN et Tailwind CSS. :chatgpt-content-reference{index="1"}

### Principales fonctionnalités

- Authentification et gestion des rôles
- Recherche et consultation des crèches
- Gestion des profils et des enfants
- Réservation de places
- Prise et gestion de rendez-vous
- Avis et commentaires
- Gestion des crèches et de leur agenda

Ces fonctionnalités correspondent aux principaux cas d'utilisation définis pour les parents, responsables de crèches et administrateurs. :chatgpt-content-reference{index="2"} :chatgpt-content-reference{index="3"}

## English

Academic team project developed at the National Higher School of Computer Science (ESI Algiers) during the 2022/2023 academic year.

### Description

**La Crèche d'à Côté** is a web application designed to help parents search for and explore childcare centers in Algeria according to different criteria.

The platform allows users to search for childcare centers, view detailed information, book a place, schedule appointments, and leave reviews. It also provides dedicated features for childcare center managers and administrators. :chatgpt-content-reference{index="4"}

### Technologies

- React.js
- Node.js
- Express.js
- MongoDB / Mongoose
- Tailwind CSS

The application was built using the MERN stack together with Tailwind CSS. :chatgpt-content-reference{index="5"}

### Main Features

- Authentication and role management
- Childcare center search and browsing
- User profile and child management
- Place reservations
- Appointment scheduling and management
- Reviews and comments
- Childcare center and agenda management

These features reflect the main use cases designed for parents, childcare center managers, and administrators. :chatgpt-content-reference{index="6"} :chatgpt-content-reference{index="7"}
